# MedLocator

Este projeto é uma solução completa para localização de postos de saúde, consulta de medicamentos/vacinas e gerenciamento de usuários, com frontend em Next.js e backend em Python (FastAPI e Flask).

---

## Web App

Acesse o aplicativo online:  
**[https://medlocator-six.vercel.app/](https://medlocator-six.vercel.app/)**
